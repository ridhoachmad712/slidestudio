# Publikasi repositori

Unggah **isi folder kit sebagai akar repositori**. Jangan unggah folder percakapan, ZIP distribusi, atau berkas sementara.

Nama yang disarankan: `slidestudio`. Deskripsi: “Skill dan template untuk presentasi kuliah PPTX/PDF yang mengikuti kebutuhan dosen.” Topik relevan: `education`, `lecture-slides`, `powerpoint`, `ai-skills`, `teaching`.

Gunakan pilihan Template repository jika tersedia. Periksa galeri dan tautan setelah publikasi. Status workflow diketahui setelah dijalankan di GitHub.

Versi paket **0.1.0** adalah rilis awal yang disiapkan; tag dan GitHub Release belum dibuat. Gunakan versi yang sama saat membuat rilis dan lampirkan ZIP bila diperlukan. Gambar galeri dapat dipakai sebagai pratinjau sosial.

Periksa file sebelum commit. `.gitignore` tidak menghapus file yang sudah dilacak. Jangan publikasi data mahasiswa atau sumber terbatas. Pastikan atribusi dan hak distribusi aset.
